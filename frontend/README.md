# Expense App Frontend

A modern React + Vite dashboard UI scaffold for the Personal Finance & Expense Tracker.

## Features

- Responsive SaaS-style dashboard layout
- Sidebar + top navigation
- Mobile drawer and bottom navigation
- Dashboard, Transactions, Budgets, Goals, Savings, Analytics, Profile, Settings
- Design system with cards, charts, tables, and status badges


This frontend is designed to connect to the existing backend via JWT auth and REST API endpoints. The current scaffold uses mock data placeholders and reusable UI components.
